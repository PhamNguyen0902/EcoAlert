# EcoAlert bilingual UI policy

EcoAlert supports only `vi` and `en`. The preferred default is `vi`; each client persists an explicitly selected locale locally and applies it immediately. Formatting utilities may use `vi-VN` and `en-US`, but the application preference is always `vi` or `en`.

## Presentation boundary

Database and API values remain stable machine codes. Clients translate those codes only at display time through:

- `frontend/src/lib/domain-i18n.ts`
- `mobile/src/utils/domainI18n.ts`

Never store translated versions of status, category, severity, AI mode, Vision class, or workflow codes. Do not translate citizen titles/descriptions, officer notes, admin notes, or chat messages.

## Canonical terminology

| Code | Vietnamese | English |
| --- | --- | --- |
| `PENDING` | Chờ xác minh | Pending |
| `VERIFIED` | Đã xác minh | Verified |
| `ASSIGNED` | Đã phân công | Assigned |
| `IN_PROGRESS` | Đang xử lý | In Progress |
| `RESOLVED` | Đã xử lý | Resolved |
| `CLOSED` | Đã đóng | Closed |
| `LOW` / `MEDIUM` / `HIGH` / `CRITICAL` | Thấp / Trung bình / Cao / Nghiêm trọng | Low / Medium / High / Critical |
| `FULL_MULTIMODAL` | Phân tích đa phương thức đầy đủ | Full Multimodal |
| `SEMANTIC_ONLY` | Chỉ phân tích ngữ nghĩa | Semantic Only |
| `VISION_ONLY` | Chỉ phân tích hình ảnh | Vision Only |

Unknown severity and missing confidence must display as unavailable/not determined, never as a fabricated `0%` or an enum code. Vision labels are presentation-only; custom YOLO names such as `plastic_bag` do not change.

## AI summaries and legacy alerts

New semantic requests ask for Vietnamese and English public summaries and short reasons in one structured provider response. The existing English `overallSummary` and `shortReason` fields are retained for compatibility; clients use locale-specific fields when present and otherwise display the existing stored text. This does not make a second provider call and does not request or persist hidden reasoning.

## Translation parity and review

`mobile/src/i18n/en.ts` is typed as `Translations` from `vi.ts`, so TypeScript rejects missing English keys. Web parity is checked by `frontend/src/lib/domain-i18n.test.ts`. For every new system-generated UI string, add both locales and use a central translation or domain-display helper. Keep third-party weather prose behind the weather-condition presentation helper.

## Audit scope and intentionally untranslated text

Reviewed system-generated paths include the global switcher, shared incident status/progress, timeline, AI overall/Vision cards, and weather card/details on both clients. Remaining literal strings in the repository must be reviewed before each feature release; user-authored content, backend logs, test fixtures, CSS values, route names, and canonical enum declarations are intentionally not translated.
